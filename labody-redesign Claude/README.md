# LA BODY — файлы сайта

## Состав проекта
- `index.html` — главная
- `services.html` — каталог услуг и цен
- `total-reset.html` — программа Total-Reset
- `about.html` — о студии

- `assets/` — логотип и карта LA BODY

## Как открыть на компьютере
1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` двойным щелчком.
3. Для проверки локальным сервером откройте терминал в папке проекта и выполните `python -m http.server 8000`. В браузере откройте `http://localhost:8000`.

## Как посмотреть на телефоне по Wi-Fi
1. Подключите компьютер и телефон к одной сети Wi-Fi.
2. Откройте командную строку Windows в папке сайта и выполните `ipconfig`. Найдите строку `IPv4-адрес`, например `192.168.1.25`.
3. В папке проекта запустите сервер командой `python -m http.server 8000 --bind 0.0.0.0`.
4. На телефоне откройте браузер и введите `http://192.168.1.25:8000`, заменив пример на IPv4-адрес вашего компьютера.
5. Если Windows спросит о доступе для Python, разрешите доступ для частной сети.

## Как сделать, чтобы сайт открывался без VPN
Сайт больше не обращается к внешним серверам (Unsplash и Google Fonts блокируются без VPN).
Фото и шрифты нужно один раз скачать в папку сайта:
1. Включите VPN.
2. Дважды щёлкните `download-assets.bat` (или выполните `python download-assets.py`).
3. Дождитесь «Готово». В папках `assets/img` и `assets/fonts` появятся файлы.
4. Выкладывайте папку целиком на хостинг — посетителям VPN не нужен.
Пока файлы не скачаны, сайт всё равно открывается: вместо фото показывается мягкая заливка, шрифты — системные.

## Неоновая подсветка услуги
Кнопка «Подробнее» на главной ведёт в каталог и подсвечивает нужные разделы (на 7 секунд). Карточка «Массаж и SPA-ритуалы» подсвечивает «Массаж и уход за телом» и «SPA-ритуалы»; «Эстетическая косметология» — программы по уходу, пилинги, маски, чистки и экспресс-уходы. Клик по любому пункту каталога на странице услуг тоже подсвечивает раздел.

## Реклама, которую клиент меняет сам
- Откройте `promo-editor.html` в браузере, заполните поля, нажмите «Скачать promo-config.js» и загрузите файл на хостинг вместо старого. Новый баннер положите в папку `assets`.
- Можно и вручную: все тексты, ссылка, картинка, частота показа и даты акции лежат в `promo-config.js`.

## Блок «до/после»
Положите настоящие фото гостей (с их письменного согласия) в `assets/results/` под именами `case1-before.jpg`, `case1-after.jpg`, `case2-before.jpg`, `case2-after.jpg`. Пока файлов нет, блок скрыт. Посмотреть макет: добавить `?preview=1` к адресу главной.
